# Деплой на Timeweb

## 1. Подключись к серверу по SSH

```bash
ssh root@ВАШ_IP_СЕРВЕРА
# или
ssh ВАШ_ПОЛЬЗОВАТЕЛЬ@ВАШ_IP_СЕРВЕРА
```

## 2. Перейди в директорию проекта и обнови код

```bash
cd /путь/к/magaz  # обычно /root/magaz или ~/magaz
git pull origin main
```

## 3. Пересобери и перезапусти контейнеры

```bash
./deploy.sh
```

Скрипт `deploy.sh` сам:
- Подтянет последний код из git (уже сделано в шаге 2, но он повторит)
- Пересоберёт Docker-образ с новым кодом
- Перезапустит контейнеры без потери данных

## 4. Проверь логи

```bash
docker compose --env-file .env.prod logs -f app
```

Должно быть:
- `Планировщик запущен: заказы 1 мин, остатки 5 мин, сверка каталога 60 мин`
- Нет ошибок при старте

Выход из логов: `Ctrl+C`

## 5. Исправь книгу непмекН-725 вручную

После деплоя сними книгу заново, чтобы применить новую логику (архивация Ozon):

```bash
docker compose --env-file .env.prod exec app python3 manual_withdraw.py непмекН-725 ozon
```

Это:
1. Обнулит остаток на Ozon (уже 0, но безопасно повторить)
2. Заархивирует карточку через `/v1/product/archive` — она уйдёт из «В продаже»

Для WB достаточно дождаться следующей полной сверки каталога (она идёт каждый час).
При сверке `external_id` обновится на `nmID`, и корзина отработает правильно.

## Альтернатива: если deploy.sh не работает

Если скрипт `deploy.sh` по какой-то причине не работает, выполни вручную:

```bash
cd /путь/к/magaz
git pull origin main
docker compose --env-file .env.prod down
docker compose --env-file .env.prod up -d --build
```

## Что было исправлено

1. **Ozon**: `withdraw()` теперь не только обнуляет остаток, но и архивирует карточку через `/v1/product/archive`. Карточка исчезнет из раздела «В продаже».

2. **WB**: `fetch_catalog()` сохраняет `nmID` (числовой ID) в `external_id` вместо `vendorCode`. API корзины требует именно `nmID`. Старые записи с `vendorCode` обработаются fallback-логикой.

3. Оба изменения graceful: если второй шаг (архив/корзина) не прошёл — остаток уже обнулён, книга не продаётся. Ошибка только логируется как warning.
